# Яндекс Карты в приложении

Виджет задач использует JavaScript API Яндекс Карт 2.1 через системный WebView
на iOS и Android — тот же API, что и сайт. Остаются масштабирование, метки задач,
переход к задаче по нажатию и подгонка границ по всем координатам.

API-ключ передаётся при сборке, в исходном коде его нет.
Локальная настройка находится в игнорируемом файле `.config/yandex_maps.local.json`.
Для нового окружения скопируйте `config/yandex_maps.example.json` в этот файл
и укажите ключ JavaScript API (как `NEXT_PUBLIC_YANDEX_MAPS_API_KEY` на сайте).

```sh
flutter run --dart-define-from-file=.config/yandex_maps.local.json
flutter build ios --simulator --dart-define-from-file=.config/yandex_maps.local.json
```

Для CI можно передать `--dart-define=YANDEX_MAPS_API_KEY=...`.
При ограничении ключа по доменам должен быть разрешён `jospar.me`.
Без ключа доступно открытие точек во внешних Яндекс Картах.
При сетевой ошибке или таймауте есть повторная загрузка и открытие внешней карты.

Названия задач безопасно кодируются для JavaScript и HTML, переход из WebView
принимается только для ID текущих задач. Авторизация приложения не передаётся
странице карты. Координаты вне допустимого диапазона отбрасываются.
