# Кладовка в мобильном приложении

Изучены веб-компоненты ProjectStoragePage, ProjectStorageView, ChannelStorage,
ChatSummaries, FileAiAnalysisButton и серверные контроллеры project-tasks,
messages, video, ocr в локальном репозитории Orbita.

## Данные и действия

- Кладовка проекта открывается из верхней панели проекта. Собирает файлы и
  HTTP(S)-ссылки из описаний и комментариев активных и архивных задач. Загружает
  полные задачи постранично; режим board-summary намеренно не используется.
- Кладовка чата открывается вкладкой «Кладовка» внутри переписки или пунктом
  «Кладовка» на главной странице мессенджера с выбором канала/личной переписки. Загружает все страницы
  вложений и форматированных Drive-ссылок той же ветки сообщений.
- Общий экран: категории, счётчики, поиск, фильтр автора, сетка/список,
  группировка по месяцам, просмотр, скачивание, избранное, переход к источнику.
- Изображения можно приближать внутри приложения. PDF открывается встроенным
  просмотрщиком с прокруткой, масштабированием и счётчиком страниц. Остальные файлы открываются
  системным приложением через OpenFilex; если обработчик не установлен,
  доступно сохранение файла на устройство.
- Загрузка в кладовку чата создаёт обычное сообщение с вложением, которое видно
  и на сайте. Удаление собственного вложения удаляет исходное сообщение после
  подтверждения. Сервер повторно проверяет права.
- Переход к сообщению возвращает в переписку на выбранное сообщение и более
  ранний контекст. Кнопка «Показать все» возвращает полную переписку.
- Резюме встреч загружаются через video/thread-summaries с пагинацией. Детали:
  участники, решения, стенограмма, связанные задачи и прикреплённые файлы.
- Распознавание PDF/изображений запускается только после подтверждения:
  ocr/jobs → status → result → ocr/tasks. Созданные задачи попадают в инбокс
  выбранного workspace; доступна серверная отмена импорта.

## Синхронизация и ограничения

Веб и мобильное приложение используют существующие серверные файлы,
сообщения, резюме и избранное чата. Веб/сервер для этой реализации не менялись.
Избранное проекта на сайте хранится в браузере, поэтому мобильное избранное
проекта тоже локальное, с разделением по аккаунту/workspace/проекту; между
устройствами эти звёздочки не синхронизируются. Это явно отмечено в интерфейсе.
Настройки сетки и фильтра пока действуют в пределах открытого экрана.

Не выполнены реальные загрузки/удаления сообщений или OCR-импорты на рабочем
сервере при разработке: контракты и ошибки проверяются тестовыми HTTP-адаптерами.
