# План на день без времени

В мобильном ежедневнике можно выбрать день, не назначая время начала. По
умолчанию формы добавления используют «Без времени». Записи выбранного дня
показываются над расписанием. Нажатие открывает выбор времени, затем обычное
редактирование длительности и подтверждение. Отмена сохраняет запись сверху.
Меню записи позволяет вернуть её из расписания в «Без времени» или изменить день.
Выполнение и архивирование исходной задачи проекта не меняются.

## Данные

- `plannedDate`: календарная дата внутри мобильной модели.
- Серверный `scheduledAt`: UTC-момент начала или локальная полночь при `hasTime: false`.
- Без времени запись не участвует в проверке пересечений, напоминаниях по времени
  или экспорте назначенных часов в Google Календарь.
- Старые записи без обоих полей сохраняются с подписью «Без даты». День им не
  назначается автоматически. Новые записи без времени обязательно имеют день.
- Задачи и сроки проектов не импортируются автоматически. Прежняя дедупликация
  связанной задачи сохраняется: повторное добавление изменяет её запись.

## Текущий контракт личных записей

Личные записи создаются через `POST project-planner/account/tasks`.
Для записи без времени приложение передаёт `hasTime: false` и `scheduledAt`:
локальную полночь выбранного дня, переведённую в UTC. Для назначенного времени
передаётся `hasTime: true`. Поле `plannedDate` в этих запросах не отправляется.
Изменение дня, назначение и снятие времени используют
`PATCH project-planner/items/:itemId` с теми же полями.

Внутри мобильной модели запись без времени хранит день в `plannedDate`, а
`scheduledAt` остаётся null. Парсер восстанавливает день из серверного timestamp
при `hasTime: false`, поэтому часы в интерфейсе не появляются.

Добавление связанных задач проекта и Инбокса пока сохраняет отдельные маршруты
`day-tasks` и `day-inbox-tasks`: локальный `AddPlannerTaskDto` не принимает
`hasTime`. Это отдельное ограничение API. Независимое выполнение связанных
записей по-прежнему требует маршрута `/completion`.

## Перетаскивание на время в мобильном приложении

В режиме «День» запись из «Весь день» можно зажать и перетащить на временную
шкалу. Подсказка показывает время с шагом 15 минут, рассчитанное обратным
преобразованием адаптивной шкалы. У верхнего и нижнего края область прокручивается.

Отпускание над шкалой обновляет существующий `itemId` через `PlannerCubit.save`,
сохраняя длительность и связь с исходной задачей. Создание новой записи и
изменение исходной задачи не выполняются. Отпускание вне шкалы отменяет перенос;
при ошибке записи задача остаётся в «Весь день». Во время сохранения и для
внешних событий перетаскивание недоступно. Обычный тап сохраняет выбор времени
через редактор. Дополнительного серверного API для жеста не требуется.

### Изменение длительности и возврат в «Весь день»

В дневной шкале нижний маркер задачи позволяет изменить длительность с шагом
15 минут, от 15 минут до конца выбранного дня. Во время жеста используется
зафиксированная адаптивная шкала, край следует за пальцем, а подсказка показывает
новую длительность. У края экрана работает автопрокрутка. Предпросмотр сохраняется
до ответа сервера; ошибка возвращает исходный размер. Отмена касания не пишет
данные. Обновляется существующая запись, её начало и исходная задача не меняются.

Чтобы убрать время, нужно зажать название задачи и перенести её в верхнюю область
«Весь день», в том числе когда она пуста. В существующей записи сохраняются день,
длительность и связь с исходной задачей, время и напоминание сбрасываются через
`/schedule`. При ошибке запись остаётся на шкале. Внешние события и записи во время
сохранения не поддерживают эти жесты; кнопка меню остаётся доступной альтернативой.

### Перенос между временными слотами

Удержание задачи на дневной шкале запускает перенос. При перемещении сохраняется
расстояние от места захвата до начала записи; подсказка показывает новое начало
с шагом 15 минут, у края области работает автопрокрутка. После отпускания меняется
время существующей записи, длительность сохраняется. Простое удержание без переноса
не округляет исходное время и не отправляет запрос. Отмена жеста и ошибка записи
оставляют исходное время. Область «Весь день» по-прежнему принимает перенос вверх.

Маркер изменения длительности находится внутри общего источника перетаскивания:
вертикальное движение без удержания изменяет длительность, удержание выбирает
перенос. Это позволяет сохранить центрированный маркер, не перекрывая жест переноса
из середины задачи. Внешние события и записи во время сохранения недоступны для переноса.
